# 顶栏、连接和共享访问修复（0.12.18）

## 问题与实现

- 顶栏的位置之前受页面容器宽度、上边距及聊天侧栏影响。产品页顶栏固定到视口，共享 Thread UI 顶栏移到分栏上方；统一 64px 高度、12px 两侧边距、44px 菜单触摸区域。移动端保留 safe area。
- 左侧菜单只保留设备管理与设置；移除重复品牌说明、Workspaces 和 Import Session。头像菜单保留账户设置与退出。
- WiFi 连接状态使用低饱和背景和细边框，右下角合并加密锁标记；旧传输、未知加密状态、身份变化不标为安全。点击仍可查看指纹；身份变化仍须核验。
- 进入终端时安排 shell 连接；若 thread 尚未加载，先 resume，再等待 shell 初始化并连接。
- 共享卡片统一标题、身份卡片、权限及近期访问；用户身份可点击查看共享关系，权限/历史/撤销使用紧凑图标。
- Rust relay 共享列表原先硬编码 `lastAccessedAt: null` 与空 `accessEvents`。新增 SQLite 历史，只记录鉴权通过且转发成功的资源访问，普通和兼容 API 路由共用。同类短时读取按五分钟合并，每个授权保存最近 100 条、返回 20 条。不会将 relay/access 权限探测或所有者预览记录为接收方访问，也不需要解密转发内容。
- 修复前没有保存的访问记录无法追溯，发布后的新访问开始记录。

## 验证与发布

- Rust：持久化、重复请求合并、分享/授权隔离，以及普通和兼容 relay 路由真实鉴权/转发/共享列表链路。拒绝请求、失败响应、所有者不计入接收方访问。
- E2E：手机与桌面顶栏坐标一致、共享卡片和用户资料、菜单迁移、连接加密状态、未连接 thread 直接进入终端。
- 发布后使用 launchd 脱离当前 Supervisor 的进程树，预先安装、验证原生资产，再停止旧服务并启动新版。保留独立日志与回滚信息，不使用会随当前会话被杀的普通后台子进程。

### 本地检查

- Rust workspace 共 223 项检查已通过。首次并行运行中，一个既有 ACP 子进程退出测试超过 800ms 限时；单独复跑通过，其余测试及后续集成测试通过。
- ThreadWorkspaceLayout 8 项组件测试；连接图标和共享名称 4 项 Web 测试；Web TypeScript 检查通过。
- 手机及桌面专项：共享资料/访问历史/菜单迁移、跨页面顶栏位置与尺寸、终端输入和会话控制。未加载 harness 的用例显式断言点击终端发出 resume；保留真实 PTY 和 WebSocket 输入输出。
- 移动终端额外覆盖浏览器原生惯性和 visualViewport 键盘布局；不把桌面模拟器宣称为真机软键盘测试。
- 修正了共享布局 CSS 缺少闭合括号，以及 Vite 动态优化终端依赖时旧 chunk 返回 504 的测试/开发环境问题。
