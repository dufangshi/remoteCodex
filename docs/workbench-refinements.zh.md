# 工作台交互修订

本次修订替代早期工作台预览中的只读参考、原生下拉框和固定路径栏。

## 分屏与工具目标

“自动化”旁的小分屏按钮打开主题化列表。首屏直接列出当前工作区的其他会话，其后是当前设备的其他工作区和账号下的其他设备。点击工作区进入会话列表；点击其他设备先进入其工作区列表。收藏、最近访问及更新时间在各层内部排序。目录按需读取，离线或访问失败可以重试，不会切换页面当前设备。

左右会话均可独立发送消息、携带附件和处理审批，保持各自的草稿、权限与历史滚动。手机一次显示一个会话。分屏成员按账号、设备和工作区保存，包含另一端设备 ID；刷新恢复选择，未发送正文不写入布局存储。

文件浏览器、文件创建/保存、终端与设置页的会话设置跟随最后点击或聚焦的会话。工具标题显示工作区和会话用于确认目标。切换工具目标前，未保存文件会触发既有退出保护；取消后仍保留原目标及草稿。已经发出的 HTTP、文件保存和终端连接固定在发起时的设备与线程，不因随后切换焦点而改投另一端。

“设为主会话”明确切换页面路由，同时把旧主会话保留为另一端。关闭文件或终端不会退出分屏、重设分屏比例或结束后台会话。

## 输入区与设置

输入区的按钮、其菜单和图片预览等所属弹层构成同一个焦点区域。长提示词在这些区域内操作时保持展开；点击区域外才收起。短提示词及空内容仍使用单行布局。

模型名称获得更多横向空间，点击后可以选择模型和推理强度。支持推理调节的模型在名称下方显示小字强度，不支持的模型只显示名称。菜单使用离散档位滑块，支持拖动、触摸、键盘和点击档位；拖动时仅预览，释放后保存，颜色与滑钮动画随档位变化并尊重系统减少动态效果设置。输入区不再显示独立的权限按钮；设置页的“会话”分类保留模型、推理强度和权限设置。斜杠工具箱仍可打开相应会话设置。权限默认显示 Full access，已明确保存的只读或工作区写入选择保持原值；打开设置不会自动改写权限。

## 自动化

原 watches 入口并入只读“自动化”面板。用户可以查看生效规则、历史、累计触发次数及消费统计；创建、修改和执行仍由 Agent 的 CLI/API 完成。界面不提供手动创建、预览、编辑、暂停或取消规则的控制。

默认界面使用四项概览与紧凑规则卡片，手机概览排列为两列。统计口径、规则定义和连接诊断按需展开；刷新使用图标按钮。缺失数据以“—”呈现，部分覆盖保留标记。旧设备接口返回 404 时显示设备更新提示，不把请求失败呈现为空列表或零消耗；刷新失败时保留已读取的数据并标记部分统计。

统一自动化统计读取完整执行账本和持久化轮次计费记录，不受最近历史页大小限制。同一轮次只记一次账，多个规则争用同一轮次时标为归属不明，不分别重复收费。金额来自各轮次已有的价格估算；缺失用量、未定价或无法归属会明确显示覆盖限制。

收件箱投递与脚本本身不产生直接模型用量；脚本自行调用外部模型的开销不在可测范围内。Claude 原生 watches 继续展示历史投影和可确认的归属，无法确认的部分保持未知。

## 定向验收

- `e2e/workbench-targets.spec.ts`：实际 Relay 与两台隔离 Supervisor，验证跨设备选择、双边发送、文件草稿退出保护、保存目标、终端目标、设置目标及刷新恢复。桌面与手机分别执行。
- `e2e/workbench-panels.spec.ts`：独立草稿、并发发送、附件和主次交换的既有回归。
- `e2e/composer-focus.spec.ts`：长提示词下的按钮、菜单、键盘、图片预览弹层、外部失焦、模型菜单及设置入口。
- Rust 自动化统计回归及 Web API、参考会话、工作区适配器、列表和面板组件测试覆盖计费与目标绑定边界。
